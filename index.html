Thoughts on Progressive Enhancement

Progressive enhancement is a way of building websites that puts the main content first so everyone can see and use it, even if they have an older browser or a device that can’t handle fancy features. After the content is ready, you can add styles like colors and fonts, and extra interactive features like buttons or animations for people who can see them. This approach makes websites faster, easier to use, and works on phones, tablets, and computers. It also helps make websites more accessible to everyone. If you want to read more about it, check out this article: Progressive Enhancement by Matt Fantinel.

Mars Rover Project Revision and Reflection

In my first version of the Mars Rover website, the pages looked plain and were not very well organized. The FAQ section was only long paragraphs, the contact page did not have a form, and the images on the rover page were not well organized.After reviewing the project, I made several improvements. I turned the FAQ into an interactive section where questions can be clicked to show answers, created a table comparing the rovers with launch dates, landing dates, mission lengths, and power sources, resized the images, cleaned up the layout, and added a working contact form.

In the final version, I also improved the technical quality of the site. I added meta tags for keywords and descriptions, placed an email link in the footer, and ran the website through HTML validation to fix errors and make sure the pages followed proper web standards. These upgrades made the website cleaner, more organized, more accessible, and more professional.

This project helped me learn a lot about building websites. I think I did well adding interactivity, improving the layout, and fixing validation issues. Over the semester, I became more confident using HTML, CSS, and JavaScript together and solving problems when something didnt work correctly. If I could start this project again, I would plan the layout better before writing code and test earlier so I could catch issues sooner. This would make the development process smoother and save time. Overall, this project showed me how important revisions and validation are. Even small changes made a big difference in improving my website and helped me better understand how to build sites that work well for all users.
